# Samsung Keyboard for non-Samsung phones

**English** | [Русский](#русский)

Ports of the Samsung Keyboard (honeyboard), Keys Cafe and Theme Park to non-Samsung Android phones (tested on POCO / HyperOS, Android 16). This repository contains **release APKs only, no source code**.

## Downloads

| App | Release | Version |
|---|---|---|
| Samsung Keyboard | [honeyboard](https://github.com/Tsifrokayf/samsung-keyboard-port/releases/tag/honeyboard-v43) | 5.9.40.48 |
| Keys Cafe | [keyscafe](https://github.com/Tsifrokayf/samsung-keyboard-port/releases/tag/keyscafe-v12) | 1.7.00.13 |
| Theme Park | [themepark](https://github.com/Tsifrokayf/samsung-keyboard-port/releases/tag/themepark-v9) | 1.1.02.2 |

## Installation

1. Install the three APKs: Samsung Keyboard, then Keys Cafe, then Theme Park.
2. Enable the keyboard in Android settings (Language and input) and select it.
3. Grant the media permission if Theme Park asks for it.

## What works

- The keyboard appears immediately when you tap an input field
- Independent key sound volume slider (Settings, Sound and vibration)
- Second symbol layer on letter keys
- Keys Cafe: colors, effects and sound
- Theme Park themes applied to the keyboard
- Russian interface strings
- "About" window with the developer name and an update check against this repository's releases

## Known limitations

- Galaxy AI features are not available
- The voice input (microphone) key is not available
- Tested on one device family only

## Updates

Each app has an "About" window with a **Check for updates** button. It compares the build number with the latest release tagged `honeyboard-vN`, `keyscafe-vN` or `themepark-vN` in this repository and opens the download link.

- Клавиатура появляется сразу при нажатии на поле ввода
